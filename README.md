# Food Delivery Data Analysis 🍽️📊

## Overview
This project analyzes a food delivery dataset by integrating data from multiple sources:
- Orders (CSV)
- Users (JSON)
- Restaurants (SQL)

## Objectives
- Analyze user ordering behavior
- Evaluate city-wise and cuisine-wise revenue
- Measure impact of Gold membership
- Identify high-value restaurants and trends

## Tools Used
- Python
- Pandas
- SQLite
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Gold members contribute significantly to revenue
- Certain cuisines have higher average order values
- Revenue shows clear seasonal patterns

## Dataset Integration
Data was merged using LEFT JOINs to preserve all transactional records.

## Outcome
The final dataset enabled accurate business insights and answered all problem statements provided in the internship assignment.
